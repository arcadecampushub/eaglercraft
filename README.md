# Eaglercraft builds

Served for [Arcade Campus Hub](https://github.com/Nos-and-Stealzers/websitegames).

| Version | Path |
| --- | --- |
| 1.8.8 | `/1.8.8/index.html` |
| 1.12.2 | `/1.12.2/index.html` |
| 26.1.2 | `/26.1.2/index.html` |

Worlds are stored per version in the browser's IndexedDB and do **not**
carry between versions — 1.8.8 and 1.12.2 use different world formats.

`save-bridge.html` lets the hub back those worlds up to an account.
